# Motion Tokens

All motion tokens are defined in `packages/shared/src/tokens/motion.ts`. Easing curves include both CSS `cubic-bezier()` strings and React Native-compatible bezier tuples.

## Usage Guidelines

| Duration | Use Case |
|----------|----------|
| `fast` (120ms) | Micro-interactions: button presses, toggles, icon state changes |
| `med` (200ms) | Standard transitions: hover effects, panel reveals, color changes |
| `slow` (320ms) | Emphasis animations: page transitions, modal entry/exit, onboarding |

| Easing | Use Case |
|--------|----------|
| `out` | Default for most enter/appear animations (ease-out expo) |
| `in` | Exit/disappear animations |
| `spring` | Playful interactions: bouncy buttons, drag-and-drop snaps |
| `standard` | Subtle, neutral transitions (Material-style ease) |
| `outQuart` | Smooth deceleration alternative to `out` |

## CSS Custom Properties

```css
/* Easing */
--ease-out: cubic-bezier(0.16, 1, 0.3, 1);
--ease-in: cubic-bezier(0.4, 0, 1, 1);
--ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);
--ease-standard: cubic-bezier(0.4, 0, 0.2, 1);

/* Duration */
--duration-fast: 120ms;
--duration-med: 200ms;
--duration-slow: 320ms;
```
