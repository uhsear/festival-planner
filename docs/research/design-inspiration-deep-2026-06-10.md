## Recommendations


## TIER: DO-NOW (15)

### R1 [HIGH / css-only] Monochrome 5-Step Surface Palette (Zero-Shadow Elevation)
- Surface: All surfaces — page, cards, modals, hover/active/disabled states (both)
- Inspiration: Refero: Mercury (#171721→#1e1e2a→#272735), Dimension (#0a0a0a→#1d1d1d→#3d3d3d), Linear — all eliminate shadows entirely; depth from layered gray steps

Standardize exactly five neutral surface values: #0a0a0a (page/void), #1a1a1a (card), #2a2a2a (hover), #3a3a3a (active/selected), #5a5a5a (disabled). Body text: #e5e5e5 primary at 100% opacity, #a0a0a0 muted, #686868 tertiary. Eliminate ALL box-shadow on cards — depth comes from surface-color contrast + hairline borders only. Status colors (crew online/offline) must use neutral + aqua ONLY — no greens/reds anywhere. Tailwind: bg-[#0a0a0a], bg-[#1a1a1a], bg-[#2a2a2a], etc. via @layer base CSS vars. Mobile: identical hex values in StyleSheet.

### R2 [HIGH / css-only] Hairline Dividers Replace All Card Borders
- Surface: Crew hub member list, expense line items, schedule cards, poll option rows (both)
- Inspiration: Refero: Dimension (1px #e5e5e5 at 6–10% for all cards/dividers), Linear (Graphite 1px separators), Mercury — universal hairline discipline across all six reviewed systems

Replace any solid/medium-weight card borders with 1px lines. Two values only: rgba(0,232,208,0.12) (aqua hairline) for active/featured items, rgba(255,255,255,0.08) for neutral separators. No border-radius changes. Apply everywhere: crew member list rows, expense line items, schedule card separators, poll option rows, set-detail section dividers. Tailwind: border border-[rgba(0,232,208,0.12)] or border-white/[0.08]. Mobile: BorderStyle.solid with exact rgba values in StyleSheet.

### R3 [HIGH / css-only] Single-Accent Discipline — One Solid Aqua CTA Per Screen
- Surface: Crew hub actions, schedule CTAs, onboarding, set-detail drawer (both)
- Inspiration: Refero: Cash App (neon green rationed to ONE fill), Linear (acid-lime text labels only, never fills), Hyperstudio (amber single accent) — universal across all six reviewed systems

Audit every screen: exactly ONE element uses solid aqua (#00e8d0) fill at a time — the primary action. All secondary buttons: transparent fill + 1px aqua border at rgba(0,232,208,0.4) + muted text (#a0a0a0); on hover/active shift border to rgba(0,232,208,0.7) and text to #e5e5e5. Danger actions (Leave Crew, Delete Expense): coral (#ff6b5b) text-only or 1px coral outline — never solid coral fill unless sole CTA on screen. Tertiary/ghost: no border, muted text only. This is a design-token convention: --color-cta-primary: #00e8d0; --color-cta-secondary-border: rgba(0,232,208,0.4); --color-danger: #ff6b5b.

### R5 [MEDIUM / css-only] Negative Letter-Spacing on Syncopate Display Text
- Surface: Festival name hero, artist card headers, set detail title, Wrap poster year headline (both)
- Inspiration: Refero: Hyperstudio (-0.037em ultra-tight), Dimension (-0.035em), Mr. Pops — compressed display is the universal dark-premium typography convention

### R10 [MEDIUM / css-only] Animated Number Ticker for Live Metrics
- Surface: Crew hub (expense totals, member count), schedule (X attending), Wrap poster stats (both)
- Inspiration: Aceternity live counter ticker + Godly animated number ticker + Mobbin live counter exemplars (analytics dashboards)

When a numeric value changes, tween from previous to new value over 600ms using a requestAnimationFrame loop with ease-out cubic: t => 1 - Math.pow(1 - t, 3). No framer-motion. Implementation: const animate = (from, to, duration, cb) => { const start = performance.now(); const step = now => { const p = Math.min((now-start)/duration, 1); cb(Math.round(from + (to-from) * easeOut(p))); if(p<1) requestAnimationFrame(step); }; requestAnimationFrame(step); }. Render in Syncopate span for display numbers (expense totals, Wrap stats), Space Grotesk for inline counts (vote tally, member count). Wrap poster: counter runs from 0 to final value on mount, 800ms duration. Mobile: Reanimated withTiming on SharedValue, interpolate to display string.

## Deliberately rejected

- Magic Bento (multi-effect card combining spotlight + tilt + particles): Looked impressive on reactbits.dev but its value comes from piling multiple effects on one card — conflicts directly with Festie's single-accent discipline and creates visual noise on small festival screens. The individual primitives (spotlight hover R12, gradient border R19) deliver more focused impact.
- Silk / Liquid Chrome backgrounds (WebGL fluid dynamics): Extraordinary visual quality on Refero showcases but GPU cost is prohibitive for a battery-sensitive festival-environment mobile app. The CSS aurora (R30) delivers comparable ambient motion at zero render cost.
- 3D Text Reveal via GSAP + ScrollTrigger: Adding GSAP+ScrollTrigger (~60kB) for a single text effect violates the no-new-library-without-exceptional-payoff rule. Scroll-driven CSS animations (R11 timeline beam) and the staggered text reveal (R25) cover the same surface with zero dependencies.
- Typewriter / Text-Type effect on hero copy: Common and already feeling dated in 2026. Festie's Syncopate display font commands enough hierarchy on its own; a cursor blinking through festival names reads as tech-demo rather than premium product.
- Floating Dock (macOS-style bottom nav on mobile): Requires Framer Motion for the spring-scaling proximity effect. The NativeTabs + Reanimated indicator (R14) achieves the same communication — active state identity — without the library. The dock metaphor also maps awkwardly onto a 5-tab festival coordination app where tabs don't have the semantic independence dock icons imply.
- Direction-Aware Hover Overlay on cards: Requires Framer Motion for the directional reveal. Interesting on Aceternity's showcase but the directional mechanic adds complexity without a clear festival-context payoff — Festie users are looking for status and schedules, not discovering which edge they hovered from.
- Live Activities / Dynamic Island: Listed in the research as needs-library (ActivityKit, WidgetKit, expo-widgets). Apple $99 developer account + EAS build pending per memory notes (iOS distribution not yet active). Skip until iOS distribution is unblocked.
- Parallax Hero Images (multi-layer scroll on web): CSS background-attachment: fixed causes jank on iOS Safari (known compositing bug since iOS 13 — not fixed as of 2026). JS-driven parallax adds scroll listeners to an already scroll-heavy schedule page. The aqua radial glow (R8) provides the same hero depth at zero scroll overhead.
- Circular Gallery / Rolling 3D Carousel: High implementation cost for a feature with no identified Festie surface. Festival cards are best presented in a grid (R16 bento) or linear list — circular carousels test poorly for functional selection tasks.
- Expensively animated Wrap poster confetti (full-screen particle burst): The controlled bento counter reveal (R10 + R16) is more premium than full-screen confetti, which reads as low-fi. Reserve celebration energy for the SOS deactivation moment or crew-complete states.
