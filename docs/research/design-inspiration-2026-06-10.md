# Design Inspiration Research — 2026-06-10

Sources: ui.aceternity.com, styles.refero.design, mobbin.com, godly.website (83 raw patterns).

## Cross-site themes

1. Zero-shadow dark depth: Every reviewed system (Dimension, Linear, Mercury, Cash App, Hyperstudio) eliminates drop-shadows entirely, building elevation through layered surface grays (#0a0a0a → #1a1a1a → #2a2a2a), hairline inset borders, and backdrop-filter glass — a direct fit for Festie's dark festival-screen context where shadows compete with the ambient stage-lighting aesthetic.

2. Single saturated accent, maximum restraint: All six Refero design systems and every Mobbin exemplar ration their neon accent to exactly one filled element per screen. Festie's aqua #00e8d0 already has this potential; the recurring finding is that the accent loses impact when used on multiple fills simultaneously — reserving it to one solid CTA while expressing it as text, outlines, or hairlines elsewhere maximizes hierarchy at a glance.

3. CSS-first motion — no animation library required: The majority of high-impact patterns (gradient borders, scroll beams, shimmer skeletons, card hover glows, infinite carousels, shrinking headers) are achievable with @keyframes, CSS custom properties, scroll-timeline, and single lightweight JS listeners. The constraint of no framer-motion on web aligns perfectly with 2026 baseline CSS capabilities (scroll-driven animations, @property, clip-path shape()), making dependency-free motion the default rather than the exception.

4. Glass surfaces signal interactive depth: Glassmorphism with backdrop-filter: blur(16–20px) + semi-transparent dark fill + hairline border + inset top highlight appears independently across Dimension, Refero, and Godly as the dominant language for drawers, modals, and floating nav — not for entire page backgrounds. In Festie's context this maps directly to the set-detail drawer and mobile formSheet, creating a consistent 'portal' vocabulary that separates content layers without color noise.

5. Typography as motion and hierarchy: Negative letter-spacing on display fonts (−0.02em to −0.037em, seen in Hyperstudio, Dimension, Mr. Pops), weight rationing (light display + regular body), and animated variable-font axes on scroll consistently appear as low-cost, high-differentiation tools. Festie's existing Syncopate + Space Grotesk pairing is already positioned to leverage this — tightening Syncopate tracking and holding Space Grotesk at 400 weight delivers brand polish with zero new dependencies.

## Proposals (impact-per-cost ordered)

### P1 [HIGH / css-only] Glassmorphic Set Detail Drawer / formSheet
- Surface: Set detail drawer (web + mobile formSheet) (both)
- Inspiration: Refero (Dimension glassmorphic surface layering + inset top border highlight)

Apply semi-transparent dark surface (#1d1d1d at 80–85% opacity) + backdrop-filter: blur(20px) + 1px border at rgba(255,255,255,0.08) + inset 0 1px 0 rgba(255,255,255,0.06) top highlight. On web the drawer slides in from right; on mobile the formSheet animates up. The inset top highlight reads as glass edge. Zero box-shadow — depth comes from the blur alone. Sourced from Dimension's card pattern and Refero's staggered transparency pattern.

### P2 [HIGH / css-only] Monochrome Neutral Stack (5-step surface palette)
- Surface: All surfaces — page, cards, hover, active, disabled (both)
- Inspiration: Refero (zero-shadow elevation via color contrast + monochrome neutral stack)

Standardize exactly five surface values: #0a0a0a (page), #1a1a1a (card), #2a2a2a (hover), #3a3a3a (active), #5a5a5a (disabled). Body text #e5e5e5 primary, #a0a0a0 muted. Eliminate all current greens/reds from status indicators — replace with neutral + aqua (#00e8d0) only. Drop all box-shadow from cards; elevation comes from surface-color step contrast + hairline borders. Sourced from Mercury, Dimension, and Linear across Refero research.

### P3 [HIGH / small-component] Scroll-Driven Schedule Timeline with Aqua SVG Beam
- Surface: Schedule timeline/list view (web)
- Inspiration: Aceternity (timeline with sticky header + scroll beam) + Godly (scroll-driven CSS animations)

Add a thin 2px aqua (#00e8d0) vertical beam that tracks scroll position down the left gutter of the schedule list, using CSS animation-timeline: scroll() (Baseline Feb 2026) or a lightweight scroll-event listener updating a CSS custom property --progress. The beam fills from top to current scroll position. Time labels in Space Grotesk 10px stick to the gutter; event cards sit to the right. No framer-motion. Sourced from Aceternity timeline + Godly scroll-driven CSS animations.

### P4 [HIGH / css-only] Hairline Dividers Replace All Card Borders

### P5 [HIGH / css-only] Single-Accent Discipline: Aqua CTA Ration
- Surface: Crew hub actions, schedule CTAs, onboarding (both)
- Inspiration: Refero (high-saturation single accent per screen + outline-only secondary buttons)

Audit every screen to ensure exactly ONE solid aqua (#00e8d0) fill button is visible at a time (the primary action). All secondary buttons become transparent-fill + 1px aqua outline at 40% opacity + muted text; on hover opacity shifts to 70%. Danger actions (Leave Crew, Delete Expense) use coral (#ff6b5b) text-only or outline — never solid coral fill unless it is the sole CTA. This is a design-token and component convention change, not a new component. Sourced from Cash App, Linear, and Common across Refero research.
